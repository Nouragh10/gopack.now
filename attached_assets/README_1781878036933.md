# 🎒 gopack.now

> **Pack your bags. Pack your friends.**

A collaborative AI group-travel planner. One person creates a trip (destination,
dates, vibes, budget), shares a link, friends add their wishlist, vote on it, and
Claude builds a beautiful day-by-day itinerary that weaves in everyone's wishes —
all syncing in real time.

![gopack banner](banner.svg)

---

## ✨ Features

- **Trip creation** — one or more cities, date range, multiple vibes, budget tier, visibility
- **Shareable link** — `?t=<tripId>` so friends join without heavy onboarding
- **Wishlist + voting** — everyone adds places/activities; popular wishes get prioritized
- **AI itinerary** — Claude (with web search) generates a day-by-day plan; ⭐ marks wish-sourced activities
- **Live editing** — add / edit / delete activities, with per-activity Maps & calendar links, synced to everyone
- **AI packing list** — categorized, shared with the whole pack
- **Accounts & dashboard** — sign in (email or Google), see trips you host vs. joined
- **Trip chat & notifications** — real-time group chat and a notification inbox
- **Export** — itinerary as PDF, plus a full `.ics` calendar download
- **PWA** — installable, offline-aware

## 🧱 Architecture

A zero-build static frontend plus Vercel serverless API routes.

```
gopack/
├── index.html            # App shell + all screens
├── src/
│   ├── app.js            # All app logic (state, Firebase, auth, AI, rendering)
│   └── style.css         # All styles
├── api/
│   ├── itinerary.js      # Serverless proxy → Anthropic (with web search)
│   └── packing.js        # Serverless proxy → Anthropic (packing list)
├── database.rules.json   # Firebase Realtime Database security rules
├── firebase.json         # Firebase config (points to the rules)
├── scripts/
│   └── migrate.js        # One-time backfill for the per-user trip index
├── sw.js                 # Service worker (PWA caching)
└── manifest.json         # PWA manifest
```

- **Frontend:** Vanilla HTML/CSS/JS (no framework, no bundler)
- **Realtime data + auth:** Firebase Realtime Database + Firebase Auth
- **AI:** Anthropic Claude (`claude-sonnet-4-5`) via the serverless routes
- **Maps:** Google Maps + Places Autocomplete


The Firebase web config and Google Maps key live in the source (these are public
client keys). Restrict the Maps key by HTTP referrer in Google Cloud, and deploy
the database rules (below) so the database isn't world-readable.
