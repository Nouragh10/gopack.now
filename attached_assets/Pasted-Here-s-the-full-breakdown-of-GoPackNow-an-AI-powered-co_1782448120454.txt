Here's the full breakdown of GoPackNow — an AI-powered collaborative group travel planner available on both web and mobile.

What It Is
GoPackNow lets friend groups plan trips together without the usual chaos of group chats and spreadsheets. Everyone contributes wishes, votes on them democratically, and AI builds the final day-by-day plan from the top results.

Core Flow
Wish → Vote → Go

Create a trip (or join one via invite code)
Everyone adds their "Wishes" — activities, places, experiences they want
The group votes on each wish with thumbs up/down
AI reads the top wishes and generates the full itinerary
Web App
Trip Planning
Create trip — set destination, days (1–21), vibes (Culture, Beach, Adventure, Foodie, etc.), budget, start date, or toggle "let the group decide the destination"
Invite members — share a unique invite code or link; anyone can join
Pack Gate — host confirms everyone has joined before planning begins
Wishlist — real-time collaborative list; add activities and ideas
Voting — thumbs up to bubble your favorite wishes to the top
Lock votes — host can lock voting to freeze the rankings before generating
Group Decision-Making
Destination voting — if no destination is set, members submit preferences (vibes, distance, budget, pace) → AI suggests top 3 destinations → group votes
Accommodation voting — members submit hotel preferences → AI suggests stays → group votes → host confirms a winner
AI Generation
Generate Itinerary — Claude builds a full day-by-day schedule with times, activity descriptions, and categories based on the top-voted wishes
Redo Activity — dislike one item? Regenerate just that one activity without touching the rest
Generate Packing List — tailored checklist based on destination, trip vibes, duration, and budget
Itinerary & Packing
Day-by-day itinerary — timed activities with descriptions; editable by the host
Export to Google Calendar — add individual activities or the whole trip
Export to Google Maps — opens a mapped route with all locations
PDF/Print — clean styled version for printing
ICS file — download for Outlook or Apple Calendar
Packing list — categorized (Essentials, Clothing, Tech, Documents, etc.) with interactive checkboxes per member
Social & Discovery
Group Chat — real-time persistent chat per trip
Explore/Discover — public gallery of community trips and itineraries for inspiration; includes a Monthly Pick featured destination
Post-trip Review — rate the trip (stars), write a review, pick highlights, upload photos
Auth
Google sign-in or anonymous guest access
Mobile App (iOS/Android via Expo)
Everything from the web plus mobile-native features:

Navigation
Home tab — your trips with a "My Packs" horizontal scroll row
Discover tab — community trips and inspiration feed
Create tab — quick trip creation; after creating, a pack invite sheet slides up so you can instantly invite your crew
Notifications tab — trip alerts ("Itinerary ready", "New member joined", "You've been invited to a trip via pack")
Profile tab — account and settings
Mobile-Only Features
Tinder-style swipe voting — swipe right to love a wish, left to skip (in addition to tap voting)
Dynamic contextual banners — smart prompts on the trip screen (e.g. "Is the pack complete?", "Itinerary ready to view")
Haptic feedback — vibrations on swipes, votes, successful actions
Native share sheet — system-level sharing of invite links
Save Pack — after generating an itinerary, save the group as a named "Pack" (👥 button in header)
My Packs — reusable crew groups that live on your home screen
Invite Pack — when creating a new trip, tap a pack to instantly send everyone an in-app invite with one tap
Pack Invites in Notifications — friends see "You're invited to Paris via Maldives Crew" with Accept / Dismiss buttons; accepting adds them directly to the trip
AI Capabilities (Backend)
All powered by Claude via the API server (key stays server-side):

Feature	What it does
Generate Itinerary	Full day-by-day plan from group wishes + vibes
Generate Packing List	Tailored checklist per destination/vibe/budget
Suggest Destinations	Aggregates group preferences → top 3 destination options
Suggest Accommodations	Matches group budget + amenity needs → ranked options
Redo Activity	Surgically replaces one activity without regenerating the whole plan
Data & Sync
Firebase Realtime Database — all collaborative state (trips, members, wishes, votes, chat, itinerary, packing) syncs in real-time across all devices
Web + Mobile always in sync — open a trip on web, changes appear instantly on mobile
